# Keep the directory useful

- Project leads own the accuracy of their repository pages.
- The workspace maintainer updates links, templates and membership; routine uploads do not require their approval.
- Recheck the website directory and publication index periodically. These files do not update automatically.
- Record the check date and original source URL when adding a publication.
- Link to the publisher or GDI-hosted report. Do not assume public availability permits republishing its full text, illustrations or PDF.
- Keep each project’s rights/licence decision explicit. No licence for underlying publications is granted by this index.
- Use descriptive links, image alt text, headings and plain-language summaries. Avoid screenshots as the only instructions.
